# Human-AI Collaborative Game (Thesis Project)

這是一個為了人機協作研究而開發的 Pygame 遊戲。玩家將與一個 AI 代理合作，共同完成擊落目標的任務。系統會詳細記錄實驗過程中的所有互動事件，以供後續分析。

## 核心功能

- **即時協作玩法**: 玩家與 AI 代理在同一個遊戲環境中互動。
- **多種實驗情境**:
  - **No Signal**: 無法發送訊號。
  - **Human Dominant**: 僅人類可主動發送訊號。
  - **Agent Dominant**: 僅 AI 可主動發送訊號。
  - **Negotiation**: 雙方皆可發送訊號進行協商。
- **詳細資料記錄**:
  - 所有關鍵事件（如目標生成、射擊、失誤、訊號）都會被即時記錄到 CSV 檔案中。
  - 依據實驗條件與受試者 ID 自動建立獨立的資料夾。
- **多模態輸入**:
  - 支援鍵盤、滑鼠與遊戲手把（Joystick）操作。
  - 支援中文語音指令（例如「我來」、「給你」）來發送訊號。
- **動態 UI**: 包含遊戲模式選擇、教學引導、暫停選單等界面。

## 系統需求

- Python (建議 3.9 或以上版本)
- Pygame
- Vosk (用於語音辨識)
- SoundDevice

## 安裝與設定

1.  **安裝 Python**:
    請先確保您的電腦已安裝 Python。

2.  **安裝相依套件**:
    打開終端機 (Terminal / Command Prompt)，執行以下指令安裝所有必要的 Python 函式庫：
    ```bash
    pip install pygame vosk sounddevice
    ```

3.  **下載語音模型**:
    - 前往 Vosk Models 頁面下載中文模型（例如 `vosk-model-small-cn-0.22`）。
    - 將下載的檔案解壓縮。
    - 將解壓縮後的模型資料夾重新命名為 `vosk-model-small-cn-0.3`（或修改 `main.py` 中的 `self.voice_model_path` 路徑）。
    - 將此模型資料夾放到 `game/models/` 路徑底下。

## 如何運行

1.  切換到 `game` 資料夾目錄：
    ```bash
    cd "game"
    ```
2.  執行主程式：
    ```bash
    python main.py
    ```

遊戲啟動後，請在主畫面輸入受試者 ID，選擇實驗模式 (SIGNAL) 後點擊 "START" 開始。

## 操作方式

- **移動**:
  - `W, A, S, D` 或 `方向鍵`
  - 遊戲手把左類比搖桿 (Left Stick)
- **射擊**:
  - `空白鍵`
  - 遊戲手把 `A` 鍵
- **發送訊號「我來！」**:
  - `C` 鍵
  - 遊戲手把 `RT` (右扳機)
  - 語音指令：「我來」、「我可以」、「交給我」
- **發送訊號「給你！」**:
  - `X` 鍵
  - 遊戲手把 `LT` (左扳機) 或 `Y` 鍵
  - 語音指令：「交給你」、「給你」、「你去」

## 任務設定總覽

以下整理目前 `game/main.py` 裡所有跟實驗任務流程、遊戲機制相關的可調參數與規則，方便日後調整或核對。（純視覺/排版用的像素數值不列在此，只列會影響「任務設定」與資料的邏輯。）

### 回合與敵機

| 項目 | 數值 | 說明 |
| --- | --- | --- |
| `TOTAL_ROUNDS` | 6 | 一次實驗總共 6 回合 |
| `ENEMIES_PER_ROUND` | 20 | 每回合要處理（命中或漏接）20 隻敵機才會結束 |
| 敵機出生點分布 | 左 20% / 中 60% / 右 20% | 畫面可移動範圍橫向切三等分，出生時的 x 座標依此機率隨機（`reset_flight_random`）。目前**沒有**額外的「落點」機率控制，出生後的水平漂移純隨機 |
| 敵機下落速度 | vx∈[-1.5, 1.5]、vy∈[1.4, 3.0]，之後夾在 [2.0, 12.0] 內 | 生成時隨機決定，下落中偶爾（6% 機率/禎）會轉向 20°~30° |
| 敵機下落是否受人類/代理人衝突凍結影響 | 否 | 人類與代理人衝突暫停時，敵機仍會正常下落，不會跟著卡住 |

### 人類射擊

| 項目 | 數值 | 說明 |
| --- | --- | --- |
| 射擊冷卻 `human_shot_cooldown` | 0 秒（平時無限制） | 只有在「友火懲罰」生效期間（`human_penalty_until`）才會用這個冷卻值限制連續射擊 |
| 有效射擊判定範圍 | 準心圖片半徑 × 1.1 | 敵機要進到這個範圍內，這次按鍵才會被計為一次「射擊」（`round_human_shots` / `human_shots`） |
| 命中判定半徑 | `explosion_radius(48) × (1/3) × 1.8` ≈ 28.8px | 在有效射擊範圍內，還要再進到這個更小的內圈才算命中 |
| 射擊輸入方式 | 鍵盤 `空白鍵`（KEYDOWN，按一次一發）／搖桿 `A` 鍵（已做邊緣觸發，按住不會自動連發，跟鍵盤行為一致） | |
| 敵機掉出畫面下緣後 | 不論人類或代理人都無法再命中 | 用跟「漏接判定」相同的邊界（`flight_y - flight_radius > HEIGHT`） |

### 代理人（Agent）

| 項目 | 數值 | 說明 |
| --- | --- | --- |
| 基礎速度 `agent_normal_speed` | 1.8 | 每禎移動像素數的基準 |
| **slow** 狀態 | ×`max(0.85, ai_slow_factor)`，最多慢到 85% | 觸發時機：人類發「我可以/我來」，或代理人自己發「交給你」 |
| **normal** 狀態 | ×1.0 | 預設狀態 |
| **fast** 狀態 | ×1.15，且強制 `ai_active=True`（不會隨機閒置，持續積極追敵機） | 觸發時機：人類發「交給你」給代理人，或代理人自己發「我可以/交給自己」 |
| 狀態切換規則 | 以**最後一次收到的訊號**為準立即切換；新敵機生成時（`reset_flight_random`）重置回 normal | 四個觸發點都會同步清除另一個旗標，slow / fast 永遠互斥，不是「slow 優先」 |
| 代理人命中判定半徑 | `explosion_radius(48) × 0.7` = 33.6px | 加速狀態目前**不會**額外提高準度 |
| 連續射擊限制 | 同一目標最多連續開 3 槍，之後強制暫停 1.5 秒 | 避免代理人對同一敵機無限連發（`agent_consecutive_shots` / `agent_burst_cooldown_until`） |
| 近距離開火延遲 | 進入射程後隨機延遲 0.15~0.35 秒才真正開火 | 模擬反應時間 |

### 訊號系統（DIR 比率）

- 公式：`dir_ratio = dist_agent / (dist_agent + dist_human)`（代理人到敵機距離 ÷ 兩者距離總和）
- 數值越小代表代理人相對越近，越大代表人類相對越近
- 只在敵機 y 座標落在畫面高度 **25%~65%** 之間才會判斷是否發訊號，且每隻敵機只判斷一次
- 判斷規則（代理人主動發訊號）：
  - `dir_ratio < 0.4` → 發「agent_my」（我來）
  - `dir_ratio > 0.6` → 發「agent_your_left / agent_your_right」（交給你，依人類在代理人左/右動態決定）
  - `0.4~0.6` 中間地帶 → **不發訊號**
- `dir_ratio` 也會自動記錄在 `events.csv` 的每一筆事件中（呼叫端沒指定時，用當下即時位置自動算）

### 干擾與懲罰

| 項目 | 數值 | 說明 |
| --- | --- | --- |
| 友火判定半徑 `FRIENDLY_FIRE_RADIUS` | 80px | 人類射擊時若代理人在此範圍內，視為友火 |
| 友火懲罰時間 `FRIENDLY_FIRE_PENALTY_SEC` | 1.0 秒 | 觸發後代理人會被拉長射擊冷卻、人類自己的冷卻也會被拉長 |
| 準心重疊判定距離 | `PADDLE_W(100) × 0.8` = 80px | 人類與代理人準心距離小於此值視為重疊衝突 |
| 重疊懲罰時間 `OVERLAP_PENALTY_SEC` | 1.5 秒 | |
| 衝突硬凍結 | 0.5 秒 | 期間人類/代理人的移動、射擊、發訊號全部暫停（敵機不受影響，見上） |
| 衝突後護欄期 | 1.0 秒 | 硬凍結結束後的緩衝期，允許柔性分離、不會重複計為新衝突 |

### 實驗情境（Condition / Signal Mode）

| condition_code | signal_mode | 說明 |
| --- | --- | --- |
| 1 | no_signal | 雙方皆不可發送訊號 |
| 2 | human_dom | 僅人類可主動發送訊號 |
| 3 | agent_dom | 僅代理人可主動發送訊號 |
| 4 | negotiation | 雙方皆可發送訊號、可協商 |

語音指令對照（`voice_signal.py` 的 phrase_map）：
- 觸發「我來/交給我」：我来、我可以、給我、教給我、交給我
- 觸發「交給你」：交给你、教给你、你、給你、你去

### 短版動態信任量表提示

- 第 2、4、6 回合結束後的 BREAK 畫面會顯示橘色提示：「請呼叫實驗人員，填寫『短版動態信任量表』」
- 實驗全部結束（DONE 畫面）也會顯示同一提示

### Loading / 準備確認流程

| 項目 | 數值 | 說明 |
| --- | --- | --- |
| Agent 載入動畫時長 `loading_duration` | 5 秒 | 按下「確認載入 AI」後的進度條時間 |
| 長按確認時長 `ready_hold_duration` | 1.8 秒 | 長按空白鍵/Xbox A 鍵滿此時間並放開，才算「我準備好了」 |
| 判定時機 | 放開按鍵時才判定 | 就算已經按滿秒數，只要還沒放開就不會跳出「Confirm start mission」按鈕 |
| 按壓不足時的提示 | 第 1 次「聲音有點小聲…」，第 2 次以後「請放慢語速說得清楚一點」 | 以對話泡泡＋打字機效果顯示，開始打字前會先隨機播放 0.8~2.2 秒的「思考中」動畫 |
| 錄音視覺效果 | 依真實麥克風音量（`VoiceSignalListener.get_level()`）驅動 7 根波形柱高度 | 長按期間會即時啟用麥克風監聽，放開後關閉 |
